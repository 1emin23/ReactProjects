# FlipCoin React Component

## Description

The **FlipCoin** React component simulates flipping a coin and keeps track of the results. With every flip, the component displays the coin side (heads or tails) and updates the count of heads, tails, and total flips.

---

## Features

- Simulates a coin flip with a random outcome.
- Displays the result of the coin flip as an image.
- Tracks the total number of flips, the number of heads, and the number of tails.
- Includes a simple UI for interaction.

---

## Project Structure

- **Component File**: `FlipCoin.js`
- **CSS File**: `../public/css/flipCoin.css`
- **Images**:
  - `1TL_onYuz.png`: Image of the front side of a Turkish coin.
  - `1TL_arkaYuz.png`: Image of the back side of a Turkish coin.
