# ReactProjects

React ve Vite öğrenme sürecinde geliştirilen küçük uygulamaları aynı repository altında toplayan mini proje koleksiyonu.

## İçerik

### 1. Joke Generator

TypeScript ile geliştirilmiş, rastgele şaka üreten React uygulaması.

```bash
cd Projects/1-Joke-Generator
npm install
npm run dev
```

### 2. Flip Coin

React ile yazılmış, görsel animasyonla yazı veya tura sonucu üreten madeni para uygulaması.

```bash
cd Projects/2-Flip-Coin
npm install
npm run dev
```

Her iki uygulama da Vite geliştirme sunucusunda çalışır.

## Teknolojiler

- React
- Vite
- JavaScript
- TypeScript
- CSS

## Repository yapısı

```text
Projects/
├── 1-Joke-Generator/
└── 2-Flip-Coin/
```

Yeni bir mini uygulama eklerken kendi klasöründe bağımsız `package.json` ve README bulundurmanız önerilir.
